# ACTIVE 数据公开声明（Data Publication Statement）

生效：2026-11-13 · 适用：`zhubao315/{running,cycling,hiking,health}` 四个公开仓库与其 Pages 站点。
这份声明回答三个问题：这里**发布了什么**、**为什么公开**、**边界在哪**。数字口径以各仓 README「数据口径」为准。

## 1. 主动公开的内容

- **运动元数据与轨迹**：日期、时长、距离、配速/速度、爬升、心率（覆盖率有限，缺则不展示）、活动名称与 ID、GPS 轨迹——包括页面地图、`activities.json`，以及原始存档 `FIT_OUT/*.fit` 和 `run_page/data.db`。
- **健康日汇总**：睡眠结构与时长、HRV、静息/日均心率、压力、步数、训练负荷（`data/health.db` + CSV + `dashboard/data.json`）。
- **身体成分**：体重与体脂历史（好轻体脂秤，独立时间轴）。

定性：这不是「展示页顺带暴露了原始数据」，而是**把个人运动与健康档案完整开源**的主动选择——为了长期可迁移的个人数据档案、公开可验证的统计，以及给自己十年的记录一个可回看的家。

## 2. 不公开的内容（仓库中不存在）

- COROS 账号口令、任何 token / 凭据（只存在于 GitHub Actions Secrets）。
- 姓名、住址、联系方式（页面与数据集中均没有）。
- 医疗记录或诊断：所有健康内容都是传感器读数与统计观察，**不构成医疗建议**，不用于诊断。

## 3. 使用约束

数据版权归数据主体（zhubao315）。允许个人学习、研究引用（请注明来源）；禁止用于商业画像、保险/招聘等对数据主体的推断决策。

## 4. 已知代价（公开决策的一部分）

- 轨迹起终点可能暴露常驻位置；睡眠与运动时窗暴露作息规律。
- Git 历史公开后**不可撤回**：删除某个文件不等于删除记忆（详见 `ACTIVE_PRIVACY_AUDIT.md`）。
- 若上述代价将来不可接受，隐私审计文档中已列出可选处置（展示副本遮罩 / 身体成分下架 / 历史重写）及其代价评估。

## 5. 勘误与联系

发现数字、口径或本声明与实际不符：在对应仓库开 issue，或在 `zhubao315/active-watch` 开 issue（巡检系统也在该仓）。
