# Design system — ACTIVE

## Authoritative visual world (pinned — do not replace)
- Surfaces: Midnight `#07111F`, Deep Navy `#0B1D33`, Active Surface `#102A43`, Raised `#13263D`, Paper White `#F7FAFF`.
- Text: Paper White `#F7FAFF`, Soft Slate `#CBD5E1`, Muted Steel `#94A3B8`, Muted Dark `#64748B`.
- Accents: HEALTH `#38BDF8`, RUNNING `#D9F36A`, CYCLING `#FBBF24`, HIKING `#34D399`.
- Health metric colours are semantic and fixed (sleep `#6366F1`, HRV `#10B981`, RHR `#F43F5E`, stress `#F59E0B`, load `#38BDF8`).
- Type: Manrope Variable (display / wordmark, 800, tracking 2.2px), Inter Variable (reading, self-hosted from the main site — pinned brand face), Fira Code (numerals, tables, times). CJK system stack.
- Radius 12px cards / 8px controls; 4px spacing grid; 1440px shell; header 64px / 56px mobile.
- Icons: one consistent SVG family (solid silhouette sub-brand icons), 24x24 grid.

## Forbid (AI tells — absolute)
- No kicker/eyebrow above a heading; no section numbers (01/02/03) as decoration.
- No sub-11px functional text; no gradient text; no purple/blue AI palette; no glowing accents on dark.
- No nested cards; no gray text on coloured surfaces; no identical icon tiles above each heading.
- No decorative motion, no generic "introducing" chips, no redundant helper copy.

## Type ramp (target)
- functional minimum 11px (0.7rem); micro labels 11–12px; captions 12px; body 15–16px; module title 20–24px; display 32–44px; wordmark max 3rem.
- Tune line-height inversely with measure; keep CJK and numerals legible; wear the accent as weight, never as a halo.

This DESIGN.md is the reference for the Impeccable design-system rules.
